# Hostel Management System (DBMS)

A comprehensive Hostel Management System designed to streamline hostel operations through an efficient relational database. The project manages student registrations, room allocations, hostel staff, fee payments, visitor records, maintenance requests, and occupancy details while ensuring data integrity using relational database principles.

The database is designed using an Entity-Relationship (ER) model and normalized schema, with SQL queries for data retrieval, updates, reporting, and analytics. The project demonstrates core DBMS concepts, including normalization, primary and foreign key constraints, joins, aggregate functions, views, triggers, stored procedures, and transactions.

## Features

* Student registration and hostel admission
* Room allocation and occupancy management
* Hostel fee and payment tracking
* Visitor and entry record management
* Maintenance request management
* Staff and hostel administration
* SQL-based reports and analytical queries
